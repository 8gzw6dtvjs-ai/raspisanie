# КТ МТУСИ · Сайт расписания

Версия сайта с новым логотипом: фиолетовый геометрический контур на белом фоне по предоставленному образцу. Знак в шапке выполнен вектором, чтобы оставаться чётким на телефонах и компьютерах. Обновлены иконки сайта и главного экрана.

## Загрузка на GitHub Pages
1. Распакуй ZIP.
2. Открой репозиторий https://github.com/8gzw6dtvjs-ai/raspisanie и ветку main.
3. Add file → Upload files: перенеси ВСЁ СОДЕРЖИМОЕ распакованной папки в корень репозитория. Сам ZIP и внешнюю папку не загружай. index.html должен быть сразу в корне.
4. Commit changes. Дождись зелёной галочки в Actions → «Обновить расписание».
5. Открой https://8gzw6dtvjs-ai.github.io/raspisanie/ заново. При старом виде обнови страницу через Ctrl + F5.

Настройка Pages остаётся GitHub Actions. Архив содержит .github/workflows/update.yml; он включает practice.js и practice.css в публикацию. Новых зависимостей для сайта нет.

## Возможности
- Основное расписание всех найденных групп (сейчас 77), выбор группы, недели, дня и всей недели.
- Основное расписание автоматически получает изменения через GitHub Actions раз в час.
- Практика напрямую читает доступную Google-таблицу при открытии и каждые 5 минут во время просмотра. Служебные надписи и ручная кнопка убраны.
- Замены с прошлого просмотра выделяются отдельно для каждой группы в браузере пользователя.
- Светлая, тёмная и системная темы. Выбор темы и группы запоминается.
- Адаптивная версия для компьютера, iPhone и Android; офлайн-оболочка и сохранённая практика.

Проверено: синтаксис, загрузка групп и практики, история замен, подготовка ресурсов, новый логотип и отсутствие переполнения компьютерной версии. Новое оформление ранее проверено на ширинах 320, 375, 412, 768 и 1440 px. Физические телефоны в этой среде не проверялись.
