# Расписание ОИБ11-24П

Сайт с расписанием пар группы ОИБ11-24П (Колледж телекоммуникаций МТУСИ).

- Данные берутся из [таблицы расписания колледжа](https://docs.google.com/spreadsheets/d/1RRrdDgLjqfFRYhjbxTdcJY_iNvP3ZEuu/htmlview).
- Раз в час GitHub Actions запускает `update.mjs`: скачивает все листы-недели, вытаскивает пары группы и пишет `data.json`, затем публикует сайт на GitHub Pages.
- Обновить вручную: вкладка **Actions** → «Обновить расписание» → **Run workflow**.
- Другая группа: поменяй `GROUP` в `update.mjs` и `GROUP` в `index.html`.

Если что-то не сходится с таблицей, верь таблице.
