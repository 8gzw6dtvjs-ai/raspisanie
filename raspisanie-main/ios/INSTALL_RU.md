# Отдельное приложение «Расписание» для iPhone

Это приложение iOS на Swift с локальным интерфейсом в WKWebView. Safari для запуска не нужен. Требуется iOS 16 или новее.

## Как получить IPA с Windows

1. Добавьте папку `ios` и файл `.github/workflows/ios.yml` в корень репозитория. Существующие файлы сайта менять не нужно.
2. Откройте GitHub → Actions → «Собрать приложение iPhone» → Run workflow.
3. После успешного выполнения откройте запуск и скачайте `Raspisanie-iPhone` в разделе Artifacts (нужен вход в GitHub).
4. Распакуйте скачанный ZIP: внутри будет `Raspisanie-unsigned.ipa`.
5. Настройте SideStore по официальной инструкции https://docs.sidestore.io/ с первоначальной установкой через компьютер. Импортируйте IPA в SideStore. Альтернатива — AltStore Classic: https://faq.altstore.io/ .

IPA не подписан: его нельзя установить простым нажатием в «Файлах». Подпись выполняет инструмент установки с вашим Apple Account. Не вводите пароль Apple Account в GitHub Secrets или в файлы проекта. При бесплатной подписи требуется регулярное обновление; учитывайте актуальные ограничения выбранного инструмента.

## Обновление расписания

При запуске сразу показывается сохранённое расписание либо версия, вложенная при сборке. Затем приложение запрашивает свежий `data.json` с GitHub Pages и сохраняет его для работы без интернета. Потяните экран вниз для повторного запроса. Смотрите дату обновления в интерфейсе: без интернета данные могут быть устаревшими. Шрифты Google требуют сети, без неё используются резервные шрифты.

Изменения расписания не требуют новой IPA. Для изменения интерфейса нужно собрать и переустановить приложение.

## Проверка сборки

Подготовка ресурсов проверена отдельно. Саму сборку Xcode и установку на iPhone необходимо проверить запуском workflow: в среде подготовки нет macOS/Xcode. Публикация в App Store и TestFlight здесь не настроена.

## Локальная сборка на Mac

Установите Xcode, Node.js и XcodeGen, затем из корня репозитория:

```sh
node ios/scripts/prepare.mjs
cd ios
xcodegen generate
open Raspisanie.xcodeproj
```

Для подписанной сборки в Xcode укажите свою Team и включите подпись (в конфигурации проекта по умолчанию CODE_SIGNING_ALLOWED=NO).
