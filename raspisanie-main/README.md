# Расписание и учебная практика

Обычное расписание ОИБ11-24П сохранено. Вкладка «Учебная практика» читает лист ОИБ (gid=692423880) из Google-таблицы напрямую, без сборки сайта.

## Что добавлено
- Выбор группы из таблицы: сейчас ОИБ11-24П, ОИБ9-23А, ОИБ9-23Б, ОИБ9-23В.
- Выбор даты, «Все даты», ручное обновление.
- Проверка новых данных при открытии вкладки, возвращении на страницу и раз в 5 минут, пока вкладка открыта.
- Сохранение последней успешной загрузки в браузере. При ошибке показана дата сохранённой копии. Для первого открытия практики нужен интернет.
- Пустое время в источнике отображается как «Время в таблице не указано». Данные не дополняются предположениями.

Источник: https://docs.google.com/spreadsheets/d/1EobL1gXGQIg8ZKDorjweeWAKNwYYtac16jUbMAJY_O4/htmlview#gid=692423880

Google-таблица сейчас разрешает анонимный CSV-экспорт и чтение из браузера. Если владелец закроет доступ, обновления прекратятся: сайт покажет сохранённую копию или сообщение об ошибке и ссылку на источник. Новые группы появятся автоматически, если их добавят на этот же лист в существующем формате: название группы отдельной строкой, затем день / дата / время / модуль / преподаватель / лаборатория. Другие листы автоматически не подключаются.

## Публикация на GitHub Pages
1. Распакуй архив. Внутри папки raspisanie-main находятся файлы сайта.
2. Открой https://github.com/8gzw6dtvjs-ai/raspisanie и выбери ветку main.
3. Нажми Add file → Upload files. Перенеси СОДЕРЖИМОЕ папки raspisanie-main в корень репозитория, затем Commit changes. Сам ZIP и внешнюю папку загружать не нужно. index.html должен остаться в корне.
4. Обязательно перенеси папку .github вместе с остальными файлами: workflow теперь включает practice.js и practice.css в публикацию. Если веб-загрузка её пропустила, открой существующий .github/workflows/update.yml на GitHub, нажми редактирование и замени содержимое версией из архива. Сборка iPhone использует обновлённый ios/scripts/prepare.mjs.
5. Settings → Pages → Build and deployment → Source: GitHub Actions. Готовый workflow уже есть, создавать шаблон не нужно.
6. Вкладка Actions → «Обновить расписание». Дождись успешного запуска после загрузки; если он не стартовал, Run workflow → main → Run workflow.
7. Открой https://8gzw6dtvjs-ai.github.io/raspisanie/ и обнови страницу. При старом виде закрой сайт и открой его снова, чтобы активировалось обновление офлайн-кэша.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Обычное расписание по-прежнему обновляет update.mjs через GitHub Actions раз в час. Практика загружается независимо при просмотре сайта, без коммита и пересборки.

## iPhone
Safari и добавление сайта на экран «Домой» используют тот же сайт. Сохранены safe-area, темы, манифест, иконки и офлайн-оболочка. Файлы практики включены в подготовку нативного приложения командой node ios/scripts/prepare.mjs. Уже установленная IPA не получит новый интерфейс от публикации сайта: для новой вкладки в IPA нужно заново запустить workflow «Собрать приложение iPhone» и установить новую сборку по прежней инструкции ios/INSTALL_RU.md. Дальнейшие изменения практики в доступной Google-таблице не требуют новой IPA.

Проверено: 4 группы / 68 записей, распознавание CSV и дат, пустые поля, фильтры, возврат к обычному расписанию, сохранённая копия при ошибке, подготовка веб-файлов для iOS. Браузерная проверка выполнена на ширине 375 px; сборка IPA и проверка на физическом iPhone в этой среде не выполнялись.
